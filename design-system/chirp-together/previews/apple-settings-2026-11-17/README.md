Mac 使用系统独立设置窗口，分为「通用／个人设备／黑名单／本机身份与数据」，支持 ⌘,。好友位于主窗口侧栏；iOS 使用「房间／好友／我的」三个标签。好友详情承接账号指纹、设备信任及删除操作，设置页不再放好友列表。

个人设备按当前设备、有效设备、已撤销设备排序。卡片展示名称、平台、完整设备指纹和注册／上线时间；更多菜单提供重命名与适用的撤销操作，当前设备和最后有效设备的原有限制继续生效。重命名使用独立表单，撤销和删除好友均有确认。

黑名单按账号 ID 与账号密钥归并，保留每条设备撤销记录。账号封禁与单设备封禁分别标注；账号密钥只标为账号指纹，不代替设备指纹。没有记录时显示「黑名单为空」。

复现 Mac：在仓库根目录运行 `./scripts/build_and_run.sh --design-preview`，点击侧栏「好友」或打开设置。iOS Debug 应用使用 `--design-preview` 启动。两端追加 `--empty-social-preview` 可查看空好友和空黑名单。

验证使用 Xcode 27.2、macOS 27.2.1 与 iOS 27.2 的 iPhone 18 Pro 模拟器。已通过两端 Debug、未签名 Release 编译、工程与中英文资源检查、身份／好友相关测试及新增黑名单归并回归；人工核对了好友详情、设备菜单、重命名取消、黑名单及空状态，另观察了 iOS 深色好友页。按需求仅验收默认字号和手机竖屏。未执行真实账号撤销、好友写入、麦克风或媒体联调。
