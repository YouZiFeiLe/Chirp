# 加入已有的 Chirp 服务器

向管理员取得服务器的完整 HTTPS 地址和适合你设备的客户端。Mac、iPhone、Android 和 Windows 使用相同的登记与核验流程。

## 登记与登录

1. 在自己的浏览器打开管理员给出的地址，选择「申请加入」。输入 3–15 位英文字母，按提示创建通行密钥（Passkey）。点击「复制申请编号」，把完整编号交给管理员。若弄丢编号，请管理员删除原待审批申请后重新登记。
2. 获批后，在 Chirp 客户端输入并确认同一个 HTTPS 地址，按提示用通行密钥登录。浏览器会返回应用，支持扫码登录的客户端也可用手机验证。
3. 首次使用时，按提示为恢复文件设置密码（至少 16 个字符），导出 `.chirpkey` 并确认已保存。**保管好恢复文件和密码**，换机时可用它们恢复设备身份。也可以让一台已授权的旧设备扫描新设备上的配对码，核对三组安全码并完成授权。

每个账号同时只保留一个有效客户端登录，新设备成功登录会替换旧会话。退出应用或登录过期后，需要再次验证通行密钥。[设备与恢复](identity-and-friends/README.md)

## 入房与通话

登录后即可查看房间。新服务器有一个「公开大厅」，管理员也可添加房间。选中房间并加入，有密码的房间会先要求输入密码。

首次与另一台设备同房时，双方打开待核验成员，发起设备互认，通过当面或另一条可信渠道逐组比较安全码，再各自确认。房间内每一对设备都完成互认并建立本轮密钥后，就可以开麦、聊天或发送文件。以后再遇到已核验的同一台设备，可以复用信任。加好友和核验设备是两个独立操作。

如果能入房却听不到对方，先看房内是否还有待核验成员，再检查麦克风权限、静音、播放设备和对方音量。双方都就绪仍无声时，请管理员检查服务器的媒体 IP 与 UDP 7882。

## 聊天与文件

- 静音时也可以发文字。单条文字最多 4096 个 UTF-8 字节，客户端保留本次入房最近 1000 条文字和附件记录。离房后聊天记录清空。
- 单个文件最多 100 MiB，可作为图片预览的文件最多 20 MiB。发送时在线且有资格的成员自动接收。晚加入的成员从加入后开始接收。
- 要长期保存文件，请在离房或清缓存前导出。已经导出的文件由接收者保管。[附件传输规则](attachments.md)
