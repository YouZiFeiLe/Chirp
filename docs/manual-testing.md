# 人工测试与结果记录

本手册供开发和发布人员在目标环境验收。用实际安装包记录平台、版本和构建号，用真实设备验证双端听感、Passkey、锁屏和系统音频路由。新部署的用户按快速部署指南完成双人通话即可。[快速部署](../deploy/README.md) · [自动化验证](development.md)

## 准备与判定

跨平台收发准备两台运行正式客户端的设备、两个已批准普通账号 A／B、一个管理员，以及默认大厅 R0、普通测试房 R1、密码房 R2。三人互认另备账号 C，同账号接管另备一台设备。用隔离环境和专用账号测试封禁、删除、版本策略与服务故障，记录实际系统、包版本、服务端镜像、网络、耳机及预设。

按本轮发行范围选择 macOS、iOS、Android、Windows 搭配，每一组交换收发方向。设备控件和系统交互按平台选测，例如 Apple 的音频预设、Android 的 Core-Telecom 和 Windows 的 WASAPI。每种预设使用同一组轻声起句、轻尾音、停顿、双讲、风扇／键盘和外放回声样本，记录漏字、断续、底噪、回声和音量。P0 覆盖权限、隔离和核心使用，P1 覆盖边界与恢复。[Android 设备联调](../Client/android/docs/testing.md) · [Windows 验证](../Client/windows/doc/README.md)

## 快速冒烟

1. 安装并冷启动，核对实际版本与测试服务，确认没有预览参数。
2. 两端确认 API 地址，新成员登记并经管理员批准；首次登录完成恢复文件保存和二次确认，再分别登录。
3. 两个首次见面的设备加入同房。确认待核验时内容已暂停，通过独立渠道比较三组安全码并分别确认。等待新一轮配钥完成，两端各自手动开麦互读短句，再测试静音和停止收听。
4. 互发中文、图片和普通文件，导出比较摘要。
5. 错误密码、取消密码框保留原通话；正确切房只留一个入房。
6. 第三人加入后，补齐每一对缺失的设备信任。核对三端名单、恢复时的静音状态及离房后的重新配钥。
7. 在大文件传输或双向通话中测试窗口和前后台切换。Mac 关窗再开应保留通话，Windows 点主窗口的 × 应结束通话并退出应用。移动端测试锁屏及返回前台。
8. 测试管理员移出、同账号接管、离房重进及进程重启。确认旧房内容清理，冷启动时的登录行为按 LOG-07 分平台检查。

- [ ] **QR-01｜P0** 在 Mac、Windows 或 Android 上显示手机登录二维码，用另一台设备完成同域 Passkey 验证。申请端领取五分钟身份设置授权后，旧端仍在线。完成设备签名挑战并取得最终登录凭据后，确认旧会话退出。可信设备的配对码另按 DEV-03 测试。
- [ ] **QR-03｜P0**：取消、刷新、3 分钟到期、篡改／重复链接、停用及审批状态均阻止旧请求发放登录；临时断网可有界重试，不迟到接管。

## 文字、附件与缓存

- [ ] **CHAT-01｜P0**：中文／英文／emoji／多行／特殊字符按文本收发，无重复；空白拒绝、UTF-8 字节边界准确。Mac 回车、Shift＋回车、⌘Return 与输入法组合各自正确，历史滚动不被新消息强拉到底。
- [ ] **CHAT-09｜P1**：成员变化暂停发送，平滑轮换准备期可继续，本次记录／草稿保留；切换时未完成发送按失败处理，不自动换槽重发。失败可放回本次空草稿，不覆盖非空草稿，不冒称送达／已读。
- [ ] **CHAT-12｜P0**：离房、成功切房、被移出及登录失效清空记录／草稿，重进与晚加入不补历史；超过 1000 条只保留最近文字与附件消息。
- [ ] **FILE-01｜P0**：双向发图片／普通文件／空文件／精确边界文件，完整上传后自动接收。iOS 照片／iCloud 加载可取消，迟到结果不发送到新房；损坏、超限或伪装图片明确拒绝。
- [ ] **FILE-09｜P0**：图片预览正确，普通文件导出大小／SHA-256 相同，GIF 导出保留原件；同名不覆盖已有文件，长名／路径样式安全处理，取消或目录失败无残片／假成功。
- [ ] **FILE-15｜P1**：单上传、自动单下载、总计至多两下载；手动暂停不被通知重启。上传／下载中断校验前缀续传，终态不提供无效续传，取消上传后迟到完成不复活。
- [ ] **FILE-18｜P0**：32–100 MiB 传输与双向语音并行，音轨差／抖动时适当限速，恢复时暂停；记录可听质量和恢复时间，不仅看文件成功。普通换钥按原资格继续，不能向新名单重发旧文件密钥。
- [ ] **DEL-02｜P0**：固定发送开始时在线原接收者，晚加入、未建附件 SSE、离房重进均不能补收；只断单次分块不判永久离线，SSE 宽限内重连可继续，超过后旧 pending 永久 skipped，新文件仍可接收。
- [ ] **DEL-07｜P0**：多人部分回执不提前回收，全部接收或退出投递后服务端删除密文，本地成功副本仍可用；发送者不能代别人回执，回执响应丢失只重试回执。

- [ ] **DEL-14｜P0**：仅重启 app 后旧 pending 不重新登记，旧上传取消、旧分发结束并回收；仍有效的本地已验证副本不因服务器回收失效，entry 结束则正常清理。
- [ ] **CACHE-01｜P0**：下载／预览／回执等待时清全局缓存，各窗口旧密钥与预览失效，迟到任务不恢复；保留语音、文字、用户导出，随后新文件可收发。离房及重启不恢复旧密钥／缓存。
- [ ] **CACHE-08｜P1**：本机 512 MiB 包含未下载预留，服务端按房间／全局字节和对象数拒绝超限；空间不足、密文篡改／截断／换块拒绝导出和成功回执，附件目录回收不碰数据库或用户文件。

## 设备、好友、首次身份与加密恢复文件

设备授权、信任和恢复文件的预期以[V5 身份流程](identity-and-friends/README.md)为准。UI 步骤注明测试端，涉及钥匙串、VoiceOver 和系统保存面板的用例在 Apple 设备上记录。其他平台按其原生界面验证同一结果。

- [ ] **ID-01｜P0**：空 Keychain／清空本地后，仅确认服务器即可注册和发起登录；未审批、拒绝、封禁分别明确提示，无根绑定、业务凭据或旧端下线。
- [ ] **ID-02｜P0**：获批首登自动进入备份页；取消导出、无写权限、只打开系统面板均不能完成。密码少于十六个 Unicode 标量、超过 1024 UTF-8 字节和两次精确字节不同被拒绝，保留首尾空白及组合字符区别。
- [ ] **ID-02a｜P1**：新建先设置并确认密码，再弹生成确认框；确认生成后自动打开系统保存面板。取消首次保存可直接重试，另存取消不丢失已有保存／校验状态。仅在保存成功后显示可选文件校验。
- [ ] **ID-02b｜P1**：导入和备份校验均先选文件、显示文件名、确认使用，再弹出独立密码框；取消密码框保留所选文件，错误密码就地提示且可重试，正确密码后明确反馈结果。取消文件选择不报错，空文件、读取失败和超限文件明确报错，不触发解密或替换当前身份。
- [ ] **ID-03｜P0**：二次确认的完整风险说明可读。立即点击、键盘和 VoiceOver 无法绕过五秒；切后台不计时；返回重存始终可用，重进完整计时，计时结束不自动提交。动态字体与窄屏不遮挡按钮。
- [ ] **ID-04｜P0**：加密前、可靠保存后、导出后、确认后、提交在途分别强制退出。重新认证保留同根、同密文和候选设备；提交响应丢失不丢唯一材料，根冲突不能把失败候选标为有效备份。切账号／服务器与迟到导出结果不互相污染。
- [ ] **ID-05｜P0** 用同一专用账号在不同平台导出并恢复 `.chirpkey`，写明源端和目标端（如 iOS→Mac、Android→Windows）。检查新文件头为 `CHIRPKEY`。新文件改名后仍能恢复同一账号根，新设备有独立私钥。将旧导出改名为 `.chirpkey` 后应拒绝导入。错误密码、损坏文件、异常参数、重复或未知字段以及账号、origin、服务端根不匹配时保留原身份。
- [ ] **ID-06｜P1**：iPhone、iPad、Mac 分别记录固定 Argon2id 64 MiB／3／4 加解密耗时、峰值内存和前后台行为，不降低参数。完成后检查应用私有目录无待办密文，Keychain 和日志无根种子或密码。
- [ ] **DEV-01｜P0**：默认 iPhone／iPad／Mac 名称、平台、指纹正确，重命名可同步。旧设备在设置中用摄像头扫码或导入二维码图片。双方核对完整三组安全码并完成系统身份验证，新设备最终登录成功才退出旧会话。被踢的合法旧设备仍可配对，撤销的签发者不能登记新设备。

- [ ] **FR-02｜P0**：同账号换机后同步好友及具体设备信任，跨房／退出／重启不重复核验旧设备。离线删除好友或设备信任立即生效，恢复联网及版本冲突后仍共享删除，旧快照不能恢复；新根／新设备不继承旧信任。
- [ ] **FR-03｜P1**：Mac／iOS 点击远端头像进入设备互认准备页，尚未发出请求；可以单独添加好友，已有好友不重复添加。点击“开始设备互认”后，对端接受再显示三组安全码；单方确认时继续显示安全码并等待另一方，双方完成后保留成功页，关闭才返回房间。账号／设备指纹可展开，核验期间可取消。

- [ ] **VOI-01｜P0** 独自在房间建钥，检查本人昵称、默认静音及手动开麦。第二台未互认设备加入后，应关闭旧麦克风，双方不能收发新的语音、文字或附件。Apple 房间的待核验提示可进入设备互认。核对三组安全码并分别确认，等新钥和首份有效媒体许可就绪，保持静音直至手动开麦。
